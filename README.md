# EUT-Fractal-Network

EUT: Expression Universe Theory — Fractal Network Simulation
Expression Universe Theory (EUT) is an exploratory research project that seeks to model the universe as an expression system rather than a purely material or mechanistic one.
The goal is to investigate whether complex structures—such as physical laws, conserved quantities, intelligence, and even civilization—can emerge from simple iterative rules applied to a fractal, self‑referential network.

This repository contains the first computational experiments toward that goal.

🌌 Project Vision
Modern physics is built on symmetry, conservation, and mathematical structure.
EUT proposes that these features may arise from a deeper layer of expression cycles operating on a distributed network of interacting nodes.
This project aims to:
Build minimal computational models (“toy models”) that capture the essence of expression cycles
Explore how symmetry and invariance lead to conserved quantities (via Noether’s theorem)
Simulate fractal or self‑similar network structures
Investigate whether emergent behavior resembles known physical or informational laws
Provide a reproducible framework for long‑term theoretical exploration
This is not an attempt to replace physics, but to explore a new conceptual foundation that may unify structure, information, and expression.

🔬 Current Focus
The initial phase of the project focuses on three foundational tasks:
1. Toy Fractal Network Model
A minimal graph-based system where nodes update according to simple local rules.
Goal: observe emergent structure, stability, or oscillation.
2. Expression Cycle Prototype
A small iterative update rule that mimics “expression → interaction → collapse → re-expression”.
3. Noether Symmetry Test
A numerical experiment to verify whether certain update rules naturally produce conserved quantities when the system exhibits continuous symmetry.

📈 Long-Term Goals
Develop a unified mathematical description of expression cycles
Explore connections to quantum measurement, symmetry breaking, and information theory
Investigate whether intelligence emerges as a stable self-referential structure
Build large-scale simulations to test fractal universes or multi-agent expression networks
Publish results, visualizations, and theoretical notes
This repository is intended to grow over months and years, not days.
